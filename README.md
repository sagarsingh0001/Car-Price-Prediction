# 🚗 Car Price Prediction using Machine Learning
## Project Overview

Developed a machine learning regression model to predict the selling price of used cars based on various vehicle attributes such as brand, fuel type, transmission type, mileage, engine capacity, and age of the vehicle.

## Problem Statement

Estimating the fair market value of a used car is challenging due to multiple influencing factors. This project aims to build a predictive model that can accurately estimate car prices using historical vehicle data.

## Dataset
- Source: https://www.kaggle.com/datasets/adhurimquku/ford-car-price-prediction
- Number of Records: 17000+
- Features: 9
- Target Variable: Price
